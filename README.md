# AI-Based Early Detection of Alzheimer's Disease Using Speech and Machine Learning

**Team:**

* **Bhanu Prakash** — `2420030209`
* **Myneni Krishita** — `2420030443`
* **D.L.S Laasya Priya** — `2420030002`

An AI-based web application for **early Alzheimer’s disease risk screening using speech, NLP, and machine learning**. The system converts speech to text, extracts linguistic features, compares multiple ML models, and deploys the best-performing model based on experimental evaluation.

> **Note:** This project is intended strictly for educational and screening purposes and is **not a diagnostic tool or a substitute for professional medical advice**.

**Tech Stack:** Next.js · React · Tailwind CSS · FastAPI · Python · scikit-learn · PostgreSQL
